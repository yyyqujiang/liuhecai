# 澳门六合彩资料导航

这是一个不需要数据库、不需要安装依赖的静态导航网站，已适配电脑和手机，可直接部署到 GitHub Pages。

## 文件说明

- `index.html`：网页结构和文字内容（GitHub Pages 默认首页）
- `styles.css`：页面视觉、响应式布局和明暗主题
- `script.js`：搜索、移动菜单、主题切换和滚动动画
- `.nojekyll`：让 GitHub Pages 按普通静态文件发布

## 上传到 GitHub Pages

1. 在 GitHub 新建一个仓库，或打开你已经创建的仓库。
2. 点击 **Add file → Upload files**，把本目录里的 4 个文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 等待约 1–3 分钟，GitHub 会在 Pages 页面显示访问地址。

> 截图中的“自述文件”输入框只用于填写 README 项目介绍，不要把整段 HTML 粘贴到那里。真正的网站首页必须是仓库根目录中的 `index.html`。

## 修改链接或文字

用文本编辑器打开 `index.html`，搜索对应栏目名称或网址后替换即可。所有外部入口都使用新标签页打开，并带有安全属性。

## 本地预览

双击 `index.html` 即可快速查看。也可以在本目录运行任意静态文件服务器进行完整测试。
